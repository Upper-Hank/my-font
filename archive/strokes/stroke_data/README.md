# 结构参考数据

来源：https://github.com/skishore/makemeahanzi

`references.json.gz` 是 2026-09-08 从该项目 `graphics.txt` 与 `dictionary.txt` 提取合并的字符索引，保留 strokes、medians、decomposition、matches，用于结构配准和部件候选标签。该索引不是训练权重，不提供神经网络推理。
