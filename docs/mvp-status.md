## 本次更新：Web GUI 与真实照片

根据新的定位，前几个工程步骤已经转成同一个本机 Web 工作台。沿用 Python 服务，增加独立 CSS/JS，没有引入前端框架或云端存储。

- **模板工作台**：字表预设、TXT 导入、自动去重、格子大小选择、多页即时预览、保存后 PDF 下载。即时预览和 PDF 共用同一排版渲染器；修改已保存模板不会覆盖原记录，下载按钮不会冒充未保存的新内容。
- **照片流程**：上传后按 QR 自动匹配模板；保留原照片，修正方向、透视与缓变光照，显示确认页后再转换。原照片不会因重新上传或返回而删除。
- **逐字核对**：原图、二值图、矢量切换；勾选或排除后生成字体。
- **字体试用**：可输入文字、调整字号、查看缺字提醒；OTF 下载以及包含 Candidates.glyphs 和 images/ 的 ZIP 下载。
- **必要的可用性处理**：自动生成内部记录名、处理中按钮状态、原位错误提示、空白字表拦截、重复确认复用结果、移动端布局。

已用本次用户提供的倒置 JPEG 实际验证。二维码匹配现有 `mvp` 模板的 `7f66c8f04a12-001` 页。旧流程在约 0.685 mm 的标记拟合残差处拒绝；新的明确照片分支利用印刷格框校准各格裁切原点，不按手写墨迹包围盒缩放或居中。照片模式统一物理比例，并保留每格平移量；严重形变和无法定位格框的页面仍会拒绝。

**真实结果：56 个手写字提取为待核对候选，56 字进入预览 OTF。** 输出另含两个空格和 `.notdef`，因此 cmap 覆盖为 58、glyph 总数为 59。这不代表 56 字的书写内容或所有细节已经人工通过，也不代表 Glyphs 原生验收已完成。

## 已交付

- 一个本地 Python 包，提供 `doctor / template / process / build / check` 五个命令。
- 4 页 A4 模板，190 个去重字符；每页 PNG、PDF、带校验值的页面 manifest。
- 四角 ArUco 定位，页面 QR 匹配，统一纸面坐标裁切；缺定位标记或错模板直接拒绝。
- 原扫描副本、灰度图、二值图、Potrace SVG、字体坐标路径与转换参数留档。
- 核对图、空白/触边清单、可直接用于生成下一批模板的 `rewrite.txt`。
- 直接生成可编辑 `Candidates.glyphs`（包含图片参考）与独立预览 `Preview.otf`、`proof.png`、覆盖清单。
- 输出目录拒绝覆盖。两份 Glyphs 辅助脚本负责导入候选和采用候选；已有字的轮廓不被导入操作覆盖，采用时保留旧图层。

MVP 使用 `.glyphs` 单文件，未引入 `.glyphspackage`、数据库、任务服务、复杂事务回执或独立 GUI。人工编辑后的字体从 Glyphs 导出，CLI 不重新编译人工编辑文件。

## 运行环境

Python 3.13.5，macOS arm64；项目虚拟环境 `.venv`；Potrace 1.16。Python 依赖锁定在 `requirements.lock`，安装命令见 README。

本机 Glyphs 3.3 / build 3306。尝试原生界面连接时，计算机控制工具返回 `timeoutReached`；因此没有确认应用内打开、背景图叠合、脚本运行、最终导出及目标应用安装效果。不能把 glyphsLib 读回等同于原生 Glyphs 验收。

## 已完成验证

仅 3 个自动回归场景，命令：

```sh
.venv/bin/python -m unittest discover -s tests -v
```

结果：3/3 通过。

1. **透视扫描到字体**：用明确标为模拟的几何笔画生成扫描，含“口”的孔洞、偏位横线和英文 A。校正后对应 Unicode 正确，位置、大小未按每字归一化；Glyphs 源文件读回与 OTF 轮廓吻合；FreeType 渲染确认孔洞保留。CFF 整数舍入容差为 1 font unit。
2. **拒绝不可靠输入和覆盖**：缺四角标记被拒绝；空白/触边被识别并从预览排除；重复向同一输出目录运行不会修改已有文件。
3. **人工编辑保护**：借助 glyphsLib 对象模型和应用接口替身运行两份脚本，先修改已有轮廓，再重导入两次，确认只增加一份候选且人工轮廓不变；采用候选后，旧轮廓可从历史层取得。该项验证脚本逻辑，原生 API 兼容性仍待验收。

此外以默认 **600 dpi** 处理配置完成一次命令行交付链：6 格模拟扫描 → 4 个有效候选、1 个空白、1 个触边 → 7 个字体 glyph（含 `.notdef` 和两个空格），字体检查通过并生成实际渲染图。标记拟合最大残差约 0.081 mm，仅代表这张模拟页面的标记拟合，不代表真实扫描精度或独立几何误差。

## 下一步实际使用

先写模板第一页并提供 PNG/TIFF 扫描。工程用真实样本确认模板尺寸是否自然、阈值是否损伤笔画、小点是否保留、背景图与轮廓是否对齐，再调整必要参数。验证通过后才扩大到剩余页面。

当前未做：自动判错字、手机局部形变修复、真实笔迹质量保证、精细英文 kerning、中文标点逐类宽度、多字形、正式字体全套审计、跨平台使用兼容性。先依据真实样本解决阻断问题，不扩展成完整生产平台。
