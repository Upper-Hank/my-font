# 产品需求：字形库与导出工程

> 当前 MVP 边界与未来功能以 [2026-09-09 范围决策](roadmap.md) 为准：拆笔画已下线隔离；项目文件与 SVG 导入为后续规划。产品定位见 [字记是工具](direction.md)。

更新：2026-09-08。以本次用户要求为准，替代此前「切字后持续更新一份字体」的流程。

## 产品模型

- 书写模板：安排采集格子，允许同字多格；模板不是字体。
- 切字批次：保存照片与每格转换结果；不自动生成字体。
- 字形库：汇总所有批次中的全部独立样本，包括同字不同写法。样本身份是批次 + sample_id，Unicode 只用于分组。空白、触边等结果也保留并标注状态。
- 导出工程：保存选用的样本引用；MVP 每个 Unicode 选一个样本。切换或取消选择不会删除其他样本。以后可增加 alt，不在本版生成 OpenType alternates。

## GUI

React 负责交互，Python 提供数据和转换。书写模板 → 照片转字形 → 字体配置。

「字体配置」含全部字形与导出工程视图。按字符或 Unicode 搜索，按批次筛选，同字样本独立呈现。可查看原图、黑白及矢量，并回到来源批次。

选择即时保存，点击「生成预览与导出」才编译 OTF 和 Glyphs 资源包。试打和下载始终指向最近成功的导出；清单变动后明确显示需要重新生成。

## 存储与失败处理

`work/runs/<batch>/<sample_id>/` 是样本文件，`run.json` 是索引；无需再复制一个字形库。`work/live/font.json` 保存导出清单及最近成功导出引用。

每次显式导出生成独立的 `work/builds/export-*/`。全部编译成功后原子更新引用；编译失败保留上一次结果。产品不展示多字体项目或历史字体卡片。原始照片、模板、样本和用户微调过的 Glyphs 文件都不因选择或导出而覆盖。

## 本版验证

前端生产构建；最小样本身份/失败保护测试；用已有真实照片的 56 字结果复制成两个测试批次，在隔离临时目录验证 112 个独立样本、同字切换、显式 OTF 导出和取消选用保留数据。复制批次仅用于验证，并不代表第二张实拍照片。未进行浏览器交互验收。

## 本地 UX 优化（2026-09-08）

保留当前视觉样式与主题。模板编辑分为内容安排、纸张与保存：批量追加保留重复字；点格后在独立输入区确认，不在中文输入过程中自动提交。支持最近 20 次内容修改撤销、删除单格和另存新模板。未提交的单格修改会阻止保存并提示处理。

上传列表支持追加、去重和逐张移除。字体配置提供字形库、切字批次、已选、待选字符和回收站。可按批次和可否选用筛选，并批量删除当前列出的样本、一整批样本或全部不可用样本（空白 / 触边）。批量选入只处理唯一可用写法且尚未选用的字符，不替换现有选择。

模板和未完成照片任务确认后即可删除，不必先进入回收站。删除切字记录会先把字形拷进字形库，再删原照片和处理文件。字形库仍先回收站再永久删除。

验证：前端构建、样本回收/恢复及导出失败保护、模板列表回收/恢复。未进行浏览器交互测试。
